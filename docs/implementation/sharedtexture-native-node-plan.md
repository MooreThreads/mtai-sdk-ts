# Internal Node-API playback binding plan

Expose SDK-internal `createPlayback(layoutWire, callback)` returning `submitEligible(frameWire,stateWire)`, `stop(session,generation,attachment,turn)`, `end()`, `close(): Promise`. Use frozen D2LM codec/target checks, preserve u64 via wire and bigint event fields, copy Buffer bytes before async ownership. Supplied STATE is resolved effective snapshot for exactly this eligible FRAME, not speculative wire metadata; reject mismatched target/allocation/PCM/state. Caller already passed shared B gate; binding never independently schedules or emits frameApplied/REUSE_ACK/native transport READY. Public host remains unwired until GPU import and full connection lifecycle exist. Audio-ready callback means actual audio acceptance only.

Per-instance Node owner keeps JS callback reference, AsyncPlayback and asynchronous cleanup hook. Explicit close resolves only after actual worker/output/uv retirement; native retirement failure rejects outstanding close promises while owner retained for explicit retry. Environment cleanup fences JS calls, requests close and keeps hook active until real retirement; no independent audio service/capture. Do not free callbacks/owner while async native work retains them. Finalizer never performs blocking PW work. Caller-visible JS callback exceptions fence native playback before surfacing failure, not fatal Node-API abort; no hidden retries/timeout. Construction failures clean references/hooks and join any initialized uv handle.

Build internal .node with raw NAPI8 (async cleanup supported), Node headers/uv/PW dependencies; no new npm pins. Device-free Node tests compile test-linked existing PW harness with narrow compile-time-only fixture modes (valid output, pending format buffers, rejected format, single disconnect failure) and actual production async worker/libuv/NAPI; never connect system PW. Exercise strict Buffer/UTF8/target/u64 BigInt, ready/emptyPCM completion/stop/close repeated identity, JS callback failure, close failure+explicit retry, GC/wrapper retention and Worker environment teardown during pending open/drain. Actual hardware tests remain separately gated. Focused all native and portable447, Astra max SPEC then independent QUALITY, bounded correction plans before edits. No recording/capture/MT-Cortex/client/app/package/runtime deployment change.
